## Projetos

**NoteControl — Sistema de Controle de Notebooks**

**ANSARAH — Projeto de Banco de Dados**

Modelagem e desenvolvimento de banco de dados relacional, utilizando SQL para organização, gerenciamento e análise de informações.

**IncluiPro — Plataforma de Inclusão Profissional**

Projeto de uma plataforma web voltada à conexão entre pessoas com deficiência e oportunidades de emprego.
